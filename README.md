# Void

A calm hole-swallowing game built from soft cubes. Press and pull to steer the hole, swallow everything, and grow.
There's no timer and no way to lose.

**Play:** open this repository's GitHub Pages link on your phone, then use **Add to Home screen** in Chrome
to install it as a full-screen app.

Maps: Farm, Reef.

Source is in `src/`. `npm install` then `npm run build` rebuilds the game into `dist/`; copy those files to the repository root to publish.
